# TUILiveKit_SwiftPM

TUILiveKit（直播 / 语聊房 UI 组件，含源码）的 SwiftPM 包。

```swift
.package(url: "https://github.com/Hanpto/LiveKit_SwiftPM.git", from: "4.3.1")
```

- product / 模块名：`TUILiveKit`
- iOS 14+，Swift 语言模式 5
- 依赖：Hanpto/AtomicX_SwiftPM（4.2.2+）、Tencent-RTC/AtomicXCore_SwiftPM、
  Tencent-RTC/RTCRoomEngine_SwiftPM、Hanpto/TUICore_SwiftPM、
  Tencent-RTC/Chat_SDK_SwiftPM、SnapKit / Kingfisher / MJRefresh

由 pod2spm 的 tools/pod2spm/publish_source.py 从源码同步生成，不要手工改。
